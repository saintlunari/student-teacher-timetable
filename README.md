# 교생 수업 배당표 자동 완성 시스템 (Harness Engineering Pro)

초등학교 교육실습생(교생)의 수업 배당표를 하네스 엔지니어링 기법을 적용하여 자동으로 완성하고, 교과 내 차시 순서 엄수, 행사/불가 일정 잠금, 시수 균등 분배, 인터랙티브 드래그 앤 드롭 조정 및 공주교대부초 표준 서식 엑셀(.xlsx) 내보내기를 지원하는 시스템입니다.

---

## 🌟 핵심 신규 기능 (v2.2 업데이트)

1. **📚 초등 표준 교육과정 차시 데이터베이스 & 원클릭 진도표 불러오기 (New)**:
   - 1~6학년, 1~2학기, 전 교과(국어, 수학, 바생, 슬생, 즐생, 사회, 과학, 도덕, 음악, 미술, 체육, 영어 등)의 단원 및 표준 차시·쪽수·주제 DB 구축.
   - Step 2에서 **[표준 교육과정 차시 불러오기]** 클릭 시 학년/학기/교과/단원을 선택하여 원하는 차시(압축/블록 포함)를 체크박스로 다중 선택하거나 단원 전체를 1초 만에 진도표에 자동 적재.
   - GitHub Pages(웹) 및 로컬 브라우저(`file:///`) 환경을 모두 지원하는 하이브리드 데이터베이스 아키텍처 (`data/curriculum_db.json` + 내장 시드 DB).
2. **📂 학교 진도표 엑셀(.xlsx) 파일 드래그 앤 드롭 임포터 (New)**:
   - 교과서 출판사나 학교에서 배포한 자체 진도표 엑셀 파일을 드래그하면, 교과/쪽수/차시/주제 열을 스마트 감지하여 즉시 진도표로 일괄 등록.
3. **🏷️ 빠른 일정 스탬프 & 나만의 프리셋 도장 시스템**:
   - 상단에서 원하는 강의(교직생활, 실습안내, 과정안작성, 미래교육 등)나 행사(수업참관, 협의회, 수업설계, 담임인사, 공휴일) 스탬프를 선택하면, 시간표 칸을 클릭할 때마다 **팝업 없이 0.1초 만에 즉시 도장 찍히듯 배치** 완료.
   - **`[+ 새 스탬프 만들기]`**: 강의명, 강의 주제, 강사 성명(교장, 수석, 부장, 외부강사 등), 테마 색상을 원하는 대로 등록하여 브라우저 로컬 저장소(`localStorage`)에 보관하고 언제든 반복 사용 가능.
   - **지우개 & 상세 편집**: 지우개 스탬프로 원클릭 삭제 지원 및 마우스 우클릭 시 언제든 상세 편집 모달 오픈.
4. **🖨️ 교생 1인 전용 맞춤 시간표 & 수업안(지도안) 마감일 캘린더**:
   - 보기 모드에서 특정 교생을 선택하면, 전체 시간표 중 **해당 교생의 수업 시간(하이라이트)**만 한눈에 들어오는 1인 전용 뷰 제공.
   - 수업일 기준 **D-3일 약안/세안 1차 제출**, **D-1일 최종안 제출** 마감일이 자동 계산되어 출력되며, **[마감일 텍스트 복사]** 버튼으로 교생 단톡방에 즉시 전송 가능.
5. **📑 한글(HWP) 표 원클릭 복사 & PNG 고화질 이미지 내보내기**:
   - 상단의 **[한글(HWP) 표 복사]** 버튼을 누른 후 아래아한글 빈 문서에서 `Ctrl + V`만 누르면 정확한 4단 표 서식(교과/쪽수/차시/수업자)이 1초 만에 자동 생성.
   - 단톡방 공유용 2배율 고해상도 PNG 이미지 원클릭 다운로드.
6. **💡 스마트 드래그 & 스왑 가이드 (Smart Swap Assistant)**:
   - 셀을 잡거나 클릭하면, 차시 순서가 유지되는 안전한 교환 위치를 🟢 **초록색 불빛**으로 안내하고, 차시 역전 슬롯은 🔴 **빨간색**으로 사전 경고.
   - 드래그 앤 드롭 외에도 **"출발 셀 클릭 → 도착 셀 클릭"** 방식의 직관적 스왑 모드 제공.
7. **📊 4대 교과군 시수 밸런스 레이더 차트 (Chart.js 대시보드)**:
   - 인문사회, 수리과학, 예체능, 생활통합 4대 교과군 레이더 차트를 겹쳐서 특정 교생에게 예체능만 몰리지 않았는지 시각적 검증.
   - 실습생의 전공 심화 교과 배정 비율(%) 및 일별 최대 수업 집중도 그래프 제공.
8. **⚡ 교과 차시 순서 100% 무결성 보장 & 압축 차시(`3~4/15`) 지원**:
   - 1교시에 2차시 분량을 다루는 압축 차시(`3~4`, `5-6`)의 1시수 인정 및 교과 진도 정밀 연동.
   - 9대 하네스 벤치마크 테스트([`test_runner.html`](file:///C:/Users/user/.gemini/antigravity/scratch/student-teacher-timetable/test_runner.html)) 100% All Passed 달성.

## 🚀 사용 방법

1. [`index.html`](file:///C:/Users/user/.gemini/antigravity/scratch/student-teacher-timetable/index.html) 파일을 더블 클릭하여 크롬/엣지 브라우저에서 엽니다.
2. 상단 우측의 **'실제 예시 프리셋'**에서 [사진 1] 또는 [사진 2]를 선택하면 실제 데이터로 배당표가 즉시 완성됩니다.
3. 보기 모드에서 교생 이름을 클릭하여 **1인 맞춤 시간표 및 지도안 마감일 달력**을 확인하고 카톡으로 복사해보세요.
4. 상단의 **[한글(HWP) 표 복사]**를 누르고 한글 문서에서 `Ctrl + V`를 눌러보세요.
5. **[Step 5 (레이더 대시보드)]** 탭으로 이동하여 교생별 교과군 레이더 차트를 확인해보세요.
