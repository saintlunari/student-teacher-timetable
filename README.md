# 교생 수업 배당표 자동 완성 시스템 (Harness Engineering Pro)

초등학교 교육실습생(교생)의 수업 배당표를 하네스 엔지니어링 기법을 적용하여 자동으로 완성하고, 교과 내 차시 순서 엄수, 행사/불가 일정 잠금, 시수 균등 분배, 인터랙티브 드래그 앤 드롭 조정 및 공주교대부초 표준 서식 엑셀(.xlsx) 내보내기를 지원하는 시스템입니다.

---

## 🌟 핵심 신규 기능 (v2.7 업데이트)

1. **🏃 특별실(체육·영어·즐생(놀이)) 사전 고정 슬롯 배치 엔진 (Dedicated Facility Fixed Slots)**:
   - 강당/체육관/운동장(체육), 영어체험실(영어), 전용 놀이실(즐생(놀이)) 등 학년/학급 공용 특별실 사용 시간에 맞추어 **사전에 정해진 요일/교시 슬롯을 지정 및 고정**할 수 있습니다.
   - 툴바의 **[특별실 고정 (체육·영어·놀이)]** 모달에서 주차별/전주차 통합 매트릭스를 통해 원클릭으로 지정하거나, 학급 기본 시간표로부터 즉시 자동 동기화할 수 있습니다.
   - 하네스 솔버(`runAutoAllocation`) 실행 시 이 슬롯들을 1순위로 선점 배치하여 **차시 순서성(100% 오름차순), 동일 요일 중복 방지, 실습생 시수 공평성**을 완벽하게 충족합니다.
   - 시간표 그리드 상에 **🏃강당, 🔤영어실, 🎈놀이실** 고유 뱃지가 선명하게 표시되며, 빈 슬롯 상태에서도 사전 고정 과목 안내 뷰를 제공합니다.
2. **🩺 배당 시수 불일치 원인 자동 진단 보고서 (Discrepancy Diagnostic Engine)**:
   - 교생별 목표 쿼터(`국(3) 수(2)...`)와 실제 배정 시수 사이에 차이가 발생할 경우, **[배당 진단 (N건)]** 배지와 함께 진단 보고서 모달을 제공합니다.
   - 단순 무작위 배정이나 침묵 대신 **교과 진도표 차시 부족, 가용 수업 슬롯 부족, 1인 최대 시수 상한 도달, 동일 요일 중복 방지 제약** 등 정확한 미달 원인과 구체적 해결 가이드를 사용자에게 명확히 안내합니다.
3. **🧩 교과 진도표 연속 순차 배정 (중간 차시 건너뜀 0건 보장)**:
   - 미배정 과목 슬롯 제거 및 인증/대표수업 사전 확정 후에도 남아있는 일반 수업 슬롯에 대해 오름차순 연속 차시를 재매핑하여 **중간 차시가 비정상적으로 누락되거나 건너뛰는 현상을 100% 방지**합니다.
4. **🔄 맞춤 교환 선택 모달 (수업자만 맞교환 vs 수업 전체 맞교환)**:
   - 배당표 및 맞춤 달력에서 수업 위치를 교환할 때, **"👤 수업자(교생)만 맞교환"**과 **"🔄 수업 전체(교과/차시/수업자) 맞교환"** 중 사용자가 원하는 방식을 선택할 수 있는 직관적인 대화상자를 제공합니다.
5. **📋 수업 수정 모달 내 교과 진도표 원클릭 자동 완성 (Curriculum Picker)**:
   - 우클릭 수업 정보 수정 모달(`modal-class-edit`)에서 번거롭게 교과명, 쪽수, 차시, 주제를 직접 타이핑할 필요 없이, **등록된 교과 진도표 목록을 실시간 검색/조회하여 원클릭으로 자동 입력**할 수 있습니다.
6. **🏷️ 빠른 일정 스탬프 & 나만의 프리셋 도장 시스템**:
   - 상단에서 원하는 강의(교직생활, 실습안내, 과정안작성, 미래교육 등)나 행사(수업참관, 협의회, 수업설계, 담임인사, 공휴일) 스탬프를 선택하면, 시간표 칸을 클릭할 때마다 **팝업 없이 0.1초 만에 즉시 도장 찍히듯 배치** 완료.
7. **🖨️ 교생 1인 전용 맞춤 시간표 & 수업안(지도안) 마감일 캘린더**:
   - 보기 모드에서 특정 교생을 선택하면, 전체 시간표 중 **해당 교생의 수업 시간(하이라이트)**만 한눈에 들어오는 1인 전용 뷰 제공.
   - 수업일 기준 **D-3일 약안/세안 1차 제출**, **D-1일 최종안 제출** 마감일이 자동 계산되어 출력되며, **[마감일 텍스트 복사]** 버튼으로 교생 단톡방에 즉시 전송 가능.
8. **📑 한글(HWP) 표 원클릭 복사 & PNG 고화질 이미지 내보내기**:
   - 상단의 **[한글(HWP) 표 복사]** 버튼을 누른 후 아래아한글 빈 문서에서 `Ctrl + V`만 누르면 정확한 4단 표 서식(교과/쪽수/차시/수업자)이 1초 만에 자동 생성.
   - 단톡방 공유용 2배율 고해상도 PNG 이미지 원클릭 다운로드.
9. **⚡ 36대 벤치마크 하네스 테스트 100% All Passed**:
   - 36대 무결성 자동 검증 테스트([`test_runner.html`](file:///c:/Users/user/Documents/GitHub/student-teacher-timetable/test_runner.html)) 100% All Passed 달성.

## 🚀 사용 방법

1. [`index.html`](file:///c:/Users/user/Documents/GitHub/student-teacher-timetable/index.html) 파일을 더블 클릭하여 크롬/엣지 브라우저에서 엽니다.
2. 상단 우측의 **'실제 예시 프리셋'**에서 [사진 1] 또는 [사진 2]를 선택하면 실제 데이터로 배당표가 즉시 완성됩니다.
3. 보기 모드에서 교생 이름을 클릭하여 **1인 맞춤 시간표 및 지도안 마감일 달력**을 확인하고 카톡으로 복사해보세요.
4. 상단의 **[한글(HWP) 표 복사]**를 누르고 한글 문서에서 `Ctrl + V`를 눌러보세요.
5. **[Step 5 (레이더 대시보드)]** 탭으로 이동하여 교생별 교과군 레이더 차트를 확인해보세요.
